# マージタウン ルール

六角形の街に区画を置いて会社を立ち上げ、株を買い、合併で稼ぐ経済ゲーム。
2〜6人、1ゲーム約10分。オリジナルルール（実装は `js/logic.js`）。

## 用意

| 項目 | 内容 |
|---|---|
| 盤面 | 六角形 61マス（中心から半径4）。行 A〜I、列 1〜 の番号つき |
| 区画タイル | 盤面のマスと1対1で対応する 61枚。よく混ぜて山にする |
| 会社 | 5社（あかね建設・あおば交通・こがね銀行・しろがね電機・むらさき不動産）。各社 株10枚 |
| 所持金 | 全員 3,000 |
| 手札 | 各自タイル 3枚 |
| 初期配置 | 山から 3枚を盤面に置く（たがいに隣り合わない）。誰の会社でもない「空き区画」になる |
| 手番 | 最初の手番はランダム。以降は時計回り |

## ゲームの長さ

全員の手番の合計が決まっている（ホストが選ぶ）。

| 長さ | 手番の合計 | 目安 |
|---|---|---|
| みじかめ | 24 | 約6分 |
| ふつう | 36 | 約10分 |
| ながめ | 48 | 約15分 |

1人あたりの手番数 = 合計 ÷ 人数（端数は切り上げ）。全員が同じ回数ずつ手番をする。

## 手番の流れ

1. **区画を置く**: 手札から1枚選んで、そのマスに置く
2. **株を買う**: 盤面にある会社の株を、合計 **2枚まで** いまの株価で買える（買わなくてもよい）
3. **引く**: 山から引いて手札を3枚に戻す

### 置いたときに起きること

置いた区画と、それにつながる区画のかたまりを見る。

| かたまりの中身 | 起きること |
|---|---|
| 置いた区画だけ | 空き区画になる |
| 空き区画だけ（2マス以上） | **会社を設立**。置いた人が盤面にない会社から1社選ぶ。置いた人は株を1枚もらい、その会社の**社長**になる |
| 会社1社＋空き区画 | その会社が空き区画ごと広がる |
| 会社2社以上 | **合併**（下記） |

盤面に5社すべてが出ているとき、新しい会社ができる場所には置けない（そのタイルは「使えない」と表示される）。

### 株価

**株価 = 会社の区画数 × 100**（全社共通）。

### 合併

1. いちばん大きい会社が残り、ほかの会社を吸収する。大きさが同じなら置いた人が残す会社を選ぶ
2. 吸収される会社ごとに、すぐに精算する
   - **買い取り**: その会社の株を持つ人は、1枚につき **株価 × 1.5** を受け取る。株は会社に戻る
   - **社長ボーナス**: 吸収された会社の社長は **区画数 × 100** を受け取る
3. 吸収された会社は盤面から消え、あとでまた設立できる（社長はいなくなり、株は10枚に戻る）
4. 残った会社の社長は変わらない

### 中間決算

ゲームのちょうど半分の手番が終わったとき、1回だけ配当がある。

- 株主: 1枚につき **区画数 × 10**
- 社長: さらに **区画数 × 30**

### 使えないタイル

置けないタイルは、引く段階で自動的に山の底に戻して引き直す。手札に置けるタイルが1枚もないときは、置かずに株を買う段階へ進む。

## ゲームの終わり

手番の合計に達したら終了。すべての会社について、

- 株主は持ち株を **株価 × 1** で売る
- 社長は **区画数 × 100** を受け取る

所持金がいちばん多い人の勝ち。同点は同順位。

## オンライン

- 部屋コードは 4桁の数字。最初に入った人がホスト
- 手番の人が60秒以上操作しないと、ホストが「代わりに進める」（CPUの判断で1手進める）を押せる

## ひとりモード

CPU 1〜5体と対戦する。通信なしで端末の中だけで動く。テストプレイはここで行う。
